# 할 일 앱 PRD

2026-10-10 작성. 서버 이전, 반복 할 일, 해빗트래커를 더하는 개편의 기준 문서다. 같은 날 네 단계를 모두 만들어 서버에 반영했고, 아래 내용은 실제로 만들어진 모습과 같다.

## 배경과 문제
개편 전의 앱은 브라우저 한 곳(localStorage)에만 저장하는 정적 페이지였다.

- 기기마다 목록이 따로다. 휴대폰에서 적은 것을 PC에서 볼 수 없고, 브라우저 데이터를 지우면 사라진다.
- 매일 하는 일(운동, 독서 등)을 날마다 다시 적어야 한다.
- 날짜가 바뀌면 완료 항목을 지우므로, 무엇을 며칠이나 꾸준히 했는지 남지 않는다.

## 목표
- 어느 기기에서 열어도 같은 목록을 본다.
- 반복되는 일은 한 번만 정해 두면 해당하는 날의 목록에 알아서 나온다.
- 루틴을 얼마나 지켰는지 한 화면(해빗트래커)에서 본다.

## 하지 않는 것
- 여러 사용자 지원과 회원가입
- 푸시 알림, 리마인더
- 기존 브라우저(localStorage)에 있던 할 일 옮기기. 서버 저장소는 빈 상태로 시작한다.
- 오프라인에서 수정하고 나중에 합치는 기능

## 기능 요구사항

### 이미 있는 것 (유지)
할 일 추가·수정·삭제·완료, 카테고리(업무, 개인, 성장)와 키워드 자동 분류, 카테고리 탭과 상태 필터, 진행률 카드, 완료 항목 일괄 삭제, 날짜가 바뀌면 완료 항목 정리.

### 1-2단계: 로그인과 서버 저장

| 기능 | 내용 |
| --- | --- |
| 자체 로그인 | 비밀번호 한 번 입력 후 기기 쿠키로 30일 유지. JY Bridge와 같은 방식 (서명된 쿠키, 연속 5회 실패 시 60초 잠금) |
| 로그아웃 | 화면 아래에 로그아웃 버튼 |
| 서버 저장 | 할 일을 서버의 SQLite 파일에 저장한다. 화면은 `api/todos`를 불러 그린다 |
| 날짜 정리 | 완료한 지 하루가 지난 일회성 할 일은 목록에서 빠진다. "오늘"은 서버가 Asia/Seoul 기준으로 정한다 |
| 실패 표시 | 저장에 실패하면 화면에 알리고, 성공한 것처럼 보이지 않게 한다 |

### 2단계: 반복 할 일(루틴)

| 기능 | 내용 |
| --- | --- |
| 루틴 만들기 | 추가 폼에서 "반복"을 고르면 일회성 할 일이 아니라 루틴으로 저장된다 |
| 반복 규칙 | 매일 / 요일 지정(예: 월·수·금) / 매월 N일. 그 달에 없는 날짜(예: 2월의 31일)는 그 달의 마지막 날에 한다 |
| 카테고리 | 루틴에도 업무·개인·성장을 붙인다. 오늘 하는 루틴은 탭 개수와 진행률 카드에 할 일과 함께 센다 |
| 오늘 화면 | 위에 "오늘의 루틴", 아래에 "할 일"로 구역을 나눈다. 루틴이 하나도 없으면 루틴 구역은 보이지 않는다 |
| 오늘 해당 없는 루틴 | 접어 둔 목록으로 따로 보여 준다 (체크는 못 하고, 수정과 종료만) |
| 수행 기록 | 루틴을 체크하면 "그 날짜에 했다"는 기록이 남는다. 다음 날에는 다시 미완료로 나온다 |
| 순서 | 루틴은 만든 순서 그대로 둔다. 완료해도 자리를 옮기지 않는다 |
| 루틴 수정 | 이름, 카테고리, 규칙을 고친다. 규칙을 바꾸면 그날부터 적용되고, 지난 날짜는 당시 규칙으로 본다 |
| 루틴 종료 | 삭제가 아니라 "종료". 그날부터 목록에 나오지 않고 지난 기록은 남는다 |

저장 구조는 "루틴 정의", "규칙의 이력", "날짜별 수행 기록"으로 나눈다. 매일 할 일을 미리 만들어 두지 않고, 날짜를 열 때 규칙으로 계산한다 (서버 스케줄러가 필요 없다).

### 3단계: 해빗트래커

| 기능 | 내용 |
| --- | --- |
| 위치 | 헤더 오른쪽의 "오늘 / 습관" 전환으로 오간다. 페이지를 옮기지 않는다 |
| 화면 위쪽 | 목록이 화면 위쪽에서 바로 시작하도록 두 줄로 줄인다. 첫 줄은 제목·날짜와 "오늘 / 습관", 둘째 줄은 기간 넘기기(‹ ›)와 "주간 / 월간" |
| 기간 제목 | 한 줄에 들어가게 짧게 쓴다. 주간은 `10.5 ~ 10.11`, 월간은 `2026년 10월` |
| 주간 보기 | 월요일~일요일 일곱 칸. 루틴마다 카드 하나 |
| 월간 보기 | 종이 해빗트래커처럼 루틴마다 1일부터 번호순으로 칸을 늘어놓는다. 휴대폰에서는 한 줄 11칸(세 줄), 넓은 화면에서는 한 줄 16칸(두 줄) |
| 기간 넘기기 | 이전·다음 주(달)로 넘긴다. 오늘이 든 기간보다 뒤로는 넘기지 않는다 |
| 표시 | 한 날은 카테고리 색 동그라미 도장(월간은 그 안에 날짜, 주간은 ✓) / 안 한 날은 빈칸 / 쉬는 날은 흐리게 / 오늘은 굵은 테두리 / 아직 오지 않은 날은 점선. 한 날은 색만이 아니라 모양(네모 칸 대신 동그라미)으로도 구분한다 |
| 체크 | 칸을 누르면 도장을 찍거나 지운다. 지난 날짜도 제한 없이 고칠 수 있다. 쉬는 날과 오지 않은 날은 누를 수 없다 |
| 연속 달성일 | 오늘까지 이어진 날 수. 쉬는 날은 건너뛴다. 오늘 아직 안 했어도 어제까지의 연속은 유지되고, 오늘 하면 하루가 더해진다 |
| 달성 수 | 보고 있는 기간에서 "한 날 / 하는 날"과 백분율. 오늘 아직 안 한 것과 오지 않은 날은 세지 않는다 |
| 종료한 루틴 | 살아 있던 기간에는 "종료함" 표시와 함께 계속 보인다. 종료 전 날짜는 고칠 수 있다 |
| 시인성 | 날짜 번호, 루틴 이름, 연속 달성일은 굵고 진한 글씨로 쓴다. 쉬는 날과 오지 않은 날도 반투명으로 흐리지 않고 읽을 수 있는 회색으로 쓴다 |

### 4단계: 묶음

2026-10-11 추가. 생활하다 문득 생각난 것을 그 자리에서 적는다. 전화할 것, 확인할 것처럼 하나짜리는 지금의 할 일 그대로 쓴다. 장보기처럼 큰 틀 안에 품목이 여러 개 생기는 것은 "묶음"에 넣는다.

상위 할 일 밑에 하위 할 일을 다는 방식은 쓰지 않는다. 품목을 다 사면 "장보기" 자체가 완료되어 다음 날 지워지고, 매번 다시 만들어야 하기 때문이다.

| 기능 | 내용 |
| --- | --- |
| 묶음 | 이름과 카테고리를 가진 틀. 직접 만들고, 이름을 고치고, 지울 수 있다 (예: 장보기, 여행 준비물, 약국). 깊이는 한 단계뿐이다 (묶음 안에 묶음 없음) |
| 묶음 지우기 | 남아 있는 품목도 함께 지운다. 지우기 전에 한 번 확인을 묻는다 |
| 필터 | 카테고리 탭을 고르면 카테고리가 맞는 묶음만 보인다. 상태 필터(미완료/완료)는 펼친 품목에만 적용한다. "완료 항목 지우기"는 묶음 안의 완료 품목도 지운다 |
| 품목 | 묶음에 속한 할 일. 평범한 할 일과 같고 어느 묶음인지만 표시한다. 카테고리는 묶음의 것을 따른다 |
| 묶음은 남는다 | 품목은 지금처럼 완료한 다음 날 지워진다. 묶음은 비어도 남아서 다음에 바로 다시 쓴다 |
| 오늘 화면 | 묶음마다 "장보기 (3)"처럼 한 줄로 접혀 보인다 (숫자는 남은 품목 수). 누르면 품목이 펼쳐지고 하나씩 체크·수정·삭제한다 |
| 묶음 고르기 | 입력창 아래에 "할 일" 버튼과 묶음 버튼을 둔다. 묶음을 누른 상태로 입력하면 그 묶음에 들어간다. "할 일"을 누르면(또는 고른 묶음을 다시 누르면) 일반 할 일과 루틴을 넣는 상태로 돌아간다. 지금 고른 것은 눌린 모양으로 보인다 |
| 여러 개 한 번에 | 묶음을 고른 상태에서 "우유, 계란, 두부"처럼 쉼표로 적으면 품목 세 개로 나뉜다. 일반 할 일에서는 나누지 않는다 (문장에 쉼표가 들어갈 수 있다) |
| 연속 입력 | 등록한 뒤에도 입력창의 커서와 고른 묶음이 그대로 남는다 |
| 바로 입력 | 오늘 화면을 열면 입력창에 커서가 가 있다 |
| 진행률 | 묶음의 품목은 진행률 카드와 카테고리 탭 개수에 세지 않는다. 묶음 줄의 남은 품목 수로 따로 보여 준다 (품목 10개가 진행률을 흔들지 않게) |
| 반복 | 품목에는 반복을 붙이지 않는다. 묶음을 고르면 반복 설정은 감춘다 |

JY Bridge는 조회 전용이므로 입력은 이 앱에서만 한다.

### 5단계: 음성 입력

2026-10-11 추가. 냉장고를 보다가 우유가 떨어진 것을 봤을 때, 휴대폰을 들고 말로 바로 넣는다. 쓰는 기기는 안드로이드 휴대폰의 크롬이다.

앱 안의 마이크 버튼과 브라우저의 음성 인식(Web Speech API)을 쓴다. 지금의 쿠키 로그인을 그대로 쓰므로 토큰은 새로 만들지 않는다. AI는 쓰지 않고 정해진 규칙으로 문장을 가른다.

| 기능 | 내용 |
| --- | --- |
| 마이크 버튼 | 오늘 화면의 입력 영역에 둔다. 누르면 듣기 시작하고, 말이 끝나면 스스로 멈춘다. 듣는 동안에는 버튼 모양이 바뀌고 받아 적은 글이 보인다. 다시 누르면 넣지 않고 그만둔다 |
| 문장 가르기 | 서버가 받아 적은 문장을 가른다. 문장 앞에서 이미 있는 묶음 이름을 찾고, "추가해줘"·"넣어줘" 같은 꼬리말을 뗀 나머지가 품목이다. 예: "장보기에 우유 추가해줘" → 장보기 묶음에 "우유". "에"나 꼬리말이 없어도 묶음 이름으로 시작하면 그 묶음에 넣는다 ("짐싸기 여권"). 음성 인식이 "에"를 자주 빠뜨리거나 "의"·"애"로 받아 적기 때문이다 (2026-10-11 휴대폰에서 확인하고 바꿈) |
| 묶음 이름이 없는 문장 | 일반 할 일로 넣는다. 예: "치과 예약하기" → 할 일 "치과 예약하기". 카테고리는 화면이 지금의 키워드 자동 분류로 골라 함께 보낸다 |
| 없는 묶음 이름 | "약국에 밴드 추가해줘"처럼 "○○에 △△ 추가해줘/넣어줘" 꼴인데 ○○이 묶음이 아니면 넣지 않고 "'약국' 묶음이 없습니다"라고 알린다. 묶음을 새로 만들지 않는다 (잘못 알아들은 말로 엉뚱한 묶음이 생기지 않게). 알림의 "할 일로 넣기"를 누르면 말한 문장 그대로 일반 할 일로 넣는다 |
| 여러 품목 | 묶음에 넣을 때는 "우유랑 계란하고 두부"를 "랑"·"하고"·"그리고"와 쉼표에서 나눠 품목 세 개로 넣는다. 일반 할 일은 나누지 않는다 |
| 넣은 뒤 알림 | 묻지 않고 바로 넣는다. 화면에 "장보기에 '우유' 추가함 · 취소"를 5초 보여 준다. "취소"를 누르면 방금 넣은 것을 지운다 |
| 바로 듣기 주소 | `?voice=1`을 붙여 열면 곧바로 듣기 시작한다. 크롬의 "홈 화면에 추가"로 이 주소를 아이콘으로 두면 아이콘 한 번과 말 한마디로 끝난다. 크롬이 터치 없이는 마이크를 켜 주지 않으면, 이 주소로 열었을 때 큰 마이크 버튼을 보여 주고 한 번 누르게 한다 |
| 쓸 수 없을 때 | 음성 인식이 없는 브라우저에서는 마이크 버튼을 보여 주지 않는다. 마이크 권한을 거절했거나 아무 말도 듣지 못했으면 그 사실을 알리고 아무것도 넣지 않는다 |
| 로그인이 풀렸을 때 | `?voice=1`로 열었는데 로그인이 풀려 있으면 로그인한 뒤 같은 주소로 돌아온다 |

음성 인식은 브라우저(구글)의 서비스가 하므로, 말한 소리는 그쪽으로 전송된다.

### 6단계: 화면 줄이기

2026-10-11 추가. 휴대폰 첫 화면에서 진행률 카드, 입력 영역 네 줄, 필터 두 줄이 위를 차지해 목록이 화면 맨 아래에서야 시작했다. 기능은 그대로 두고 자리만 줄인다.

| 기능 | 내용 |
| --- | --- |
| 입력 영역 접기 | 평소에는 입력창, 마이크, "추가" 버튼 한 줄만 보인다. 카테고리·반복, "할 일"/묶음 버튼, 새 묶음 칸은 접혀 있다 |
| 펼치기 | 입력창을 누르거나 글자를 적기 시작하면 펼쳐진다. 화면을 열 때 입력창에 커서가 가 있는 것만으로는 펼치지 않는다 |
| 다시 접기 | 입력창이 비어 있고, 묶음을 고르지 않았고, 반복이 "반복 없음"이고, 새 묶음 칸이 닫혀 있을 때, 입력 영역 밖을 누르면 접힌다. 고른 것이 남아 있으면 접지 않는다 (어디에 들어갈지 안 보이면 안 되므로) |
| 접힌 채로 넣기 | 접힌 상태에서도 "추가"와 Enter, 마이크는 그대로 동작한다 |
| 진행률 카드 | 제목·요약·백분율 한 줄과 막대만 남긴다. 카테고리별 현황(업무/개인/성장 개수) 줄은 없앤다. 카테고리별 개수는 카테고리 탭의 숫자로 보고, 탭을 고르면 카드가 그 카테고리의 진행률로 바뀌는 것은 그대로다 |
| 마이크 버튼 | 한눈에 보이게 한다. 아이콘을 키우고 버튼에 옅은 파란 바탕과 파란 테두리를 준다 |
| 넓은 화면 | PC처럼 넓은 화면(900px 이상)에서는 접지 않고 늘 펼쳐 둔다 |

카테고리 탭과 상태 필터 두 줄은 이 단계에서 건드리지 않는다.

### 7단계: JY Bridge에 요약 내주기

2026-10-11 추가. JY Bridge 첫 화면의 "할 일" 카드가 읽어 갈 조회 전용 요약이다. 이 앱의 화면과 저장 구조는 바뀌지 않는다. Bridge 쪽 작업은 `freshnjy/jy-bridge`의 `docs/tasks.md` 11단계.

| 기능 | 내용 |
| --- | --- |
| 요약 API | `GET api/bridge-summary`. 오늘 하는 루틴의 수와 끝낸 수, 아직 안 한 루틴의 이름, 남은 할 일의 수와 이름을 돌려준다 |
| 인증 | `Authorization: Bearer {TODO_BRIDGE_TOKEN}`. 서버 안에서 Bridge가 부를 때만 쓴다. 쿠키로는 열리지 않는다. 토큰이 설정되지 않았으면 꺼진 상태다 |
| 조회 전용 | 이 토큰으로는 이 경로만 읽을 수 있다. 추가·수정·완료·삭제는 못 한다 |
| 부작용 없음 | 아무것도 지우거나 고치지 않는다. `GET api/todos`처럼 지난 완료 항목을 정리하지 않는다 |
| 세지 않는 것 | 묶음의 품목, 오늘 하는 날이 아닌 루틴, 종료한 루틴, 완료한 할 일 |

## 정해야 할 것
해당 단계를 시작하기 전에 사용자에게 확인한다.

7단계 전 (2026-10-11 확정, 위 표에 반영):
- Bridge 카드는 두 줄이다. 개수("루틴 2/5 · 할 일 3")와 아직 안 한 것의 이름.
- 저녁에도 내일 루틴이 아니라 오늘 못 끝낸 것을 보여 준다. 그래서 요약은 언제나 오늘 기준이다.
- 묶음 품목, 연속 달성일, 카테고리는 보내지 않는다.
- 완료 체크 같은 쓰기는 Bridge에서 하지 않는다. 입력과 체크는 이 앱에서만 한다.

6단계 전 (2026-10-11 확정, 위 표에 반영):
- 입력 영역을 접는다.
- 진행률 카드는 전체(고른 탭) 진행률만 보여 주고 카테고리별 현황 줄은 없앤다.
- 필터 두 줄은 그대로 둔다.

5단계 전 (2026-10-11 확정, 위 표에 반영):
- 방식은 앱 안의 마이크 버튼이다. 음성 비서나 다른 앱에서 서버를 부르는 방식(쓰기용 토큰 필요)은 쓰지 않는다.
- 넣기 전에 확인을 묻지 않는다. 바로 넣고 "취소"를 몇 초 보여 준다.
- 묶음 이름이 없는 문장은 일반 할 일로 넣는다.
- 없는 묶음 이름을 말하면 묶음을 만들지 않고 알린다.

- "없는 묶음"과 "일반 할 일"을 가르는 기준: "○○에 △△ 추가해줘/넣어줘"처럼 "에"와 꼬리말이 함께 있는데 ○○이 묶음이 아니면 없는 묶음으로 보고 알린다. 그 밖의 문장은 모두 일반 할 일이다. "회의록에 일정 추가해줘" 같은 할 일도 알림에 걸리므로, 알림에 "할 일로 넣기" 버튼을 함께 둔다.
- 여러 품목을 한 번에 말하면 묶음에 넣을 때만 "랑"·"하고"·"그리고"에서 나눈다 ("우유랑 계란하고 두부" → 세 개). 일반 할 일은 나누지 않는다.
- "취소"는 5초 동안 보여 준다.

4단계 전 (2026-10-11 확정, 위 표에 반영):
- 묶음은 고정하지 않고 직접 만들고 지운다.
- 쉼표로 나누는 것은 묶음 안에서만 한다.
- 진행률 카드에는 묶음의 품목을 세지 않고, 묶음 줄에서 따로 센다.

- 묶음을 지우면 남아 있는 품목도 함께 지운다. 지우기 전에 한 번 확인을 묻는다.
- "완료 항목 지우기" 버튼은 묶음 안의 완료 품목도 함께 지운다.
- 카테고리 탭을 고르면 카테고리가 맞는 묶음만 보인다. 상태 필터(미완료/완료)는 묶음 줄을 감추지 않고, 펼친 품목에만 적용한다.
- 휴대폰 홈 화면 아이콘(앱처럼 설치)은 이 단계에 넣지 않는다. 화면을 열면 입력창에 커서가 가는 것만 넣는다.

2단계 전 (2026-10-10 확정, 위 표에 반영):
- 반복 규칙은 매일, 요일 지정, 매월 N일. "매주 N회"는 넣지 않는다.
- 루틴에도 카테고리를 붙인다.
- 루틴과 할 일은 구역을 나눠 보여 준다.
- 규칙을 바꾸면 기록은 그대로 두고, 바꾼 날부터 새 규칙을 적용한다.

3단계 전 (2026-10-10 확정, 위 표에 반영):
- 해빗트래커는 같은 화면의 탭으로 둔다.
- 주간과 월간을 전환해서 본다.
- 연속 달성일은 쉬는 날을 건너뛰고, 오늘 아직 안 했어도 유지한다.
- 지난 날짜는 제한 없이 고칠 수 있다.
- 월간 보기는 종이 해빗트래커 형식(번호순 칸)으로 하고, 한 날은 X 대신 동그라미 도장으로 표시한다. 루틴별 월간 리뷰(메모)는 넣지 않는다.
- 휴대폰의 월간 보기는 한 줄 11칸으로 한다 (8칸은 달력처럼 보이고, 16칸은 누르기에 너무 작다).
- 화면 위쪽은 두 줄로 줄이고, 습관 화면의 글씨는 굵고 진하게 한다.
